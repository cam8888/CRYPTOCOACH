# 💰 CryptoCoach 🚀

**Welcome! Learn everything about crypto without spending a single cent.**

CryptoCoach is an interactive educational platform built with **Python** and **Streamlit**. It allows beginners to practice cryptocurrency trading in a risk-free environment using real-time market data.

---

## ✨ Key Features

* **📊 Live Trading Simulator:** Start with a virtual $10,000 and trade Bitcoin, Ethereum, and Solana with real-time prices.
* **📈 Dynamic Portfolio:** Track your "Net Worth" and see the value of your assets evolve based on live market volatility.
* **🎓 Crypto Academy:** Learn essential concepts like FOMO, HODL, and security through interactive lessons and quizzes.
* **📰 Smart Newsfeed:** Stay informed with curated tips and the latest market trends designed for newcomers.

---

## 🛠️ Tech Stack

* **Language:** Python 3.x
* **Framework:** [Streamlit](https://streamlit.io/) (UI & Interaction)
* **API:** [CoinGecko REST API](https://www.coingecko.com/en/api) (Live Market Data)
* **Data Handling:** Pandas & Numpy (Calculations & Simulated Charts)
